# Jalingo Climate Data Analysis 🌍🛰️

This is my first Data Science project. I used Python to connect to NASA's satellite API and pull real temperature data for my hometown, Jalingo, Nigeria.

## Tools Used:
- **Python**
- **Requests** (to connect to NASA's API)
- **Pandas** (to clean and structure the data)
- **Matplotlib** (to create the visualization)

## What the Data Shows:
The chart shows the temperature trend in Jalingo from January to May 2026, highlighting the rise in temperature during the hot season before the rains.
